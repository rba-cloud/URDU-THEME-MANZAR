See [TEST-REPORT.md](TEST-REPORT.md) for executed checks and limitations. No live deployment was performed.

## Export when an attachment download is unavailable

The complete source and ZIP are preserved in this checkout. From the repository root, run:

```sh
python3 -m zipfile -c manzar-news.zip manzar-news
```

Upload the resulting ZIP through WordPress Appearance → Themes → Add New → Upload Theme. The supplied Jameel Noori Nastaleeq font is included; see the theme README for details.
